# Кофейня «Зерно»

Веб-приложение кофейни: каталог напитков, выпечки и зерна, корзина с оформлением заказа, блог и админ-панель со статистикой.

## Основные возможности

- **Покупатель:** просмотр каталога из 13 позиций в четырёх категориях («Кофе», «Чай», «Десерты», «Зерно») с фильтром, поиском и сортировкой по цене, корзина, регистрация и вход, оформление заказа (сумму пересчитывает сервер), украшение стаканчика стикерами перетаскиванием, личный кабинет с заказами и чеками, блог со статьями.
- **Администратор:** управление товарами (добавление, изменение, скрытие, удаление, картинки), записями блога и стикерами, смена статуса заказов, удаление демо-заказов, страница статистики (выручка, число заказов, средний чек, час пикового спроса, выручка по дням, заказы по часам и категориям, продажи по товарам).

## Стек технологий

- **Backend:** Node.js 22.5+ (без внешних зависимостей, `npm install` не нужен)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), одностраничное приложение
- **База данных:** SQLite (встроенный модуль `node:sqlite`)

## Как запустить проект локально

1. Установите [Node.js](https://nodejs.org) версии 22.5 или новее.
2. Скачайте проект и распакуйте архив.
3. Откройте папку с проектом в VS Code или в консоли.
4. В терминале выполните команду: `node server.js` (или `npm start`)
5. Перейдите в браузере по адресу: http://localhost:3000

При первом запуске автоматически создастся файл базы данных `data/coffee.db`, учётная запись администратора и демо-заказы за 30 дней, чтобы страница статистики сразу была заполнена.

Настройки задаются переменными окружения: `PORT` (по умолчанию 3000), `DB_FILE`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`. Для публикации в интернете задайте свой `ADMIN_PASSWORD` до первого запуска.

## Структура проекта

- `server.js` — серверная логика, REST API, авторизация, работа с БД, раздача `public/`.
- `public/index.html` — клиентская часть (каталог, корзина, стикеры, блог, вход, админка, статистика).
- `public/img/` — картинки товаров (13 SVG-иллюстраций, можно заменить своими фото .jpg, .png, .webp).
- `data/coffee.db` — файл базы данных SQLite, создаётся при первом запуске.
- `test.js` — автотесты API (29 проверок на базе в памяти, запуск: `node test.js`).

## База данных

Таблицы: `users`, `sessions`, `products`, `posts`, `stickers`, `orders`, `order_items`. Позиции заказа хранят название и цену на момент покупки, поэтому правка каталога не меняет старые чеки.

## Безопасность

Пароли хранятся как scrypt-хеш с солью, сессия лежит в HttpOnly-cookie (SameSite=Lax), запросы на изменение требуют JSON, все обращения к базе параметризованы, права проверяются на сервере. Вход ограничен десятью попытками в минуту, раздача файлов защищена от выхода за пределы `public/`.
